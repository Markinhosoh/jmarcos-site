# JMarcos RH, site do representante

Site de uma página do J.Marcos, representante comercial para óticas (RHluxo, Salvatore, RH Kids, R.H. Beauty e marca própria).

- `index.html`: página completa (HTML, CSS e JS puros, sem build).
- `assets/`: fotos das armações e das modelos.
- WhatsApp de contato: constante `WHATSAPP` no início do script.

Para ver localmente, abra o `index.html` no navegador.
